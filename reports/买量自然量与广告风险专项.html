结论先看

有在线参数控制自然与非自然来源的广告差异，而且不是单纯的自然量开关。 已还原链路：归因融合结果 → 来源与环境风险检查 → 内部org分组 → 逐场景广告限制。自然来源会进入受限分组；非自然来源也必须满足相关检查，才能脱离该组。因此“自然用户少广告，符合条件的买量用户进入更多广告流程”有代码及在线值支撑；“所有买量用户都展示、自然用户完全无广告”不成立。

存在明显值得核查的广告风险组合：应用抽屉点图标前的插屏流程、使用第三方应用后回到桌面的插屏调用，以及按同一风险分组改变部分图标和设置入口的隐藏行为。前两项属于优先核查的打断式广告风险；后一组合具有差异展示能力，但不能仅凭静态代码证明其目的就是躲避审核。

2. 归因是怎样传到广告判断的

2.1 自然与非自然来源判定

jh0中存在Install Referrer和第三方归因融合逻辑；融合模型el5包含organic、network、campaign等字段。el5.i()对organic字符串与Organic进行忽略大小写的相等比较。

q77.e合并归因结果流jh0.J()和在线配置流scd.e()，随后q77$e$a.b把网络、campaign以及解码后的限制参数交给b87。来源检测器bq6监听融合归因结果，编号为3。

来源检测器的关键分支已被REA和字节码交叉核对：

没有融合归因结果 → UNKNOWN
organic == Organic → RSK，说明为illegal-source
非自然来源：
    ccsulso为空／缺失／解析失败 → 空关键词表 → SAFE
    关键词表非空且campaign包含任一关键词 → SAFE
    否则 → RSK，说明为illegal-camp

这里的RSK是该应用SDK内部枚举，不代表自然用户真的存在欺诈或安全风险。ccsulso筛选的是campaign字符串，不能误写成网络平台白名单。Non-Organic也只是非自然归因标签，不独立证明发生过付费投放。

证据：REA读取bq6.d、bq6解码字节码、Craft交叉读取、融合模型、归因融合、配置与归因连接。

2.3 dly是另一条时间／首日限制，不是买量判定

q77$a.c()读取first_time_niuma，gu.a()首次写当前时间。q77$a.e()在该时间缺失／异常小，或首启日期与当天DAY_OF_YEAR相同时返回true。基本判定器在此状态下检查dly<0；时间判定器把正dly乘1000，与距首启的时长比较。

4. 哪些可能违规，哪些只能说可疑

本轮已实际读取Google Play官方政策，保存HTML、正文和抓取时间。以下是根据政策与代码作出的风险评估，不是Google的处罚结论。

• 打断用户打开应用／回到桌面的插屏：高风险。 官方禁止在用户选择其他操作时突然出现全屏插屏，以及干扰其他应用和设备操作的广告。23000045与23000046应优先验证触发时机、广告是否全屏、是否明确可关闭、目标动作是否被阻断。来源：Ads。

• 按环境和归因改变可见入口、压制广告：具有规避审核的可疑组合，但动机未证实。 在线条件能把自然来源、ADB等状态纳入受限分组，且同一组影响广告与设置／图标隐藏。官方禁止审核规避、未披露的核心功能差异和远程激活的隐蔽功能；但常规反作弊或广告分层本身不能直接等同于审核规避。仍缺商店完整披露核对、实际人群UI对照、审核环境差异运行证据。来源：Deceptive Behavior，尤其Behavior Transparency。

• 隐藏设置／图标及重设桌面：需核查知情同意与恢复方式。 官方要求用户知情同意地改变相关设备设置，并可方便恢复；本次只证明控制与判断链，未观察到真实设备设置变化或用户协议流程。来源同上。

Launcher桌面本身可以是该App的界面，不能因为广告出现在桌面就自动判成应用外广告。重点是是否在用户没有预期的操作点打断正常使用、干扰其他App或系统操作，以及是否透明披露。

以下尚无足够证据，不能认定：自动点击广告／伪造曝光、强制跳转商店、假关闭按钮、无法关闭超过15秒、锁屏广告已启用、后台覆盖其他App、检测到审核身份后藏广告。不存在这些结论不代表功能不存在，而是本轮未观察到足够证据。

政策原文证据：Ads正文、Deceptive Behavior正文、抓取记录。
