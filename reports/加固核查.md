# PDF竞品第三方加固与自研保护核查

未发现可可靠归属到360、爱加密等常见整包壳的证据。TurboScan™: PDF scanner有DexGuard第三方保护特征；PDF Editor - Document Viewer和Document Hero有Google许可检查；All Document - File Viewer有应用层资源加密。五款均未确认自研整包加固。
