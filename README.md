## 如何更新网页

1. 将本仓库克隆到电脑：`git clone https://github.com/jluoxx/pdf-competitor-research.git`。
2. 解压“直接部署”ZIP，将其中的 index.html、assets、reports、evidence 等文件和文件夹复制到克隆目录根部并替换同名文件。不要上传 ZIP 本身，不要再套一层目录；保留 .git、.github、.nojekyll 和 README.md。
3. 在克隆目录打开终端，已有克隆先运行 `git pull --ff-only` 再替换文件；运行 `git add .`、`git commit -m "Update report website"`、`git push origin main`。
4. 仓库 Settings → Pages 应为 Deploy from a branch，分支 main、目录 / (root)。已配置好，平时不用重复设置。
5. 等待 Pages 构建成功，再打开上方在线阅读地址。如仍显示旧页面，按 Ctrl+F5 刷新。构建状态可在仓库 Actions 或 Settings → Pages 查看。

提交历史保留旧版，可按提交记录恢复。不要直接更改原始证据的内容来修改研究结论。
